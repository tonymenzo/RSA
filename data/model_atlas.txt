We now consider a fully general flavor structure for hadronization. Following 
the current implementation of flavor dependent hadronization parameters within
Pythia, the flavor dependent aLund is modified in the form of aExtraQQuark such 
that the true 'aLund' parameter for each quark, denoted by AQ, is given by

AQ = aLund + aExtraQQuark.

In the Lund model, the bLund parameter is 'flavor-blind' but, for experimental
fits, Pythia has a way to override this default assumption. We follow the same
conventions and set new bLund parameters for each quark through the bLund override, 
bNonstandardQ. Because of the current implementation we also have to set an
override for aLund as well - we always set this override parameter to the default 
aLund value (in order to stick with the above aExtraQQuark implementation).

Models will be classified in three ways:
    1. Hadronizing system (u-ubar, d-dbar, ... qgq, qqq, ggg, ...)
    2. Number of varied parameters (compared to reference)
    3. Euclidean distance, l, from the reference model 

The "master atlas" for all considered model parameterizations can be found below.
