-Description from report:
We perform a bootstrapped tuning procedure for parameters $a_d$ and $b_d$, while leaving other flavours at the same target and base values.
For the test runs we use a 100k simulated events and iterate through a 100 combinations of 30k subsets (both for events at the base and target parameterization) on which we perform the tuning with the same hyperparameters (described in individual figures).
For the loss function we use the $1d$ wasserstein distance $(p=2)$ of the $z_{accept}$ distribution.
We expect this to contain more information than actual physical observables and therefore the confidence ellipses should be smaller (this is to be confirmed through a comparison with a simulation using physical observables).
The results can be seen in figures \ref{fig:joker11} and \ref{fig:joker12}, which depict the same bootstrapped tuning experiment, where in the first plot the tuning paths are visualized and in the second plot the 95 \% confidence ellipse is shown.
The purpose of the test runs is also to assess the efficiency/ feasibility of the bootstrapping procedure.
The 2d plot with the current bootstrap implementation took about 6 hours to complete (using a simple iteration procedure for each individual tune - no parallelization).
When performing the tune in 3d, the time taken approximately doubles (3d: 6 hours for 48 tuning runs, 2d: $\approx 6h$ for 100 tuning runs - Might be due to CUDA error - !!check!!). 
This makes it seem feasible for performing the bootstrap estimation of the confidence ellipse, however for the brute-force computation of the coverage test (which requires multiple confidence ellipse estimations), optimization would be beneficial.
